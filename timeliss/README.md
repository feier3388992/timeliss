# ⏱️ Timeliss - 训练计时器

一款支持**语音播报**的 Android 训练计时 App，适合健身、冥想、学习等场景。

## ✨ 功能特性

- 🎯 **多种预设时长**：1/3/5/10/15/20/25/30/45 分钟
- 🎤 **语音播报**：倒计时读数、训练进度提醒、完成提示
- ⏳ **准备阶段**：可选 10 秒准备时间
- 🎨 **精美 UI**：渐变背景 + 动态动画效果
- 📱 **离线可用**：无需网络连接

## 📦 安装

1. 下载 [最新 APK](https://github.com/feier3388992/timeliss/releases)
2. 在手机上安装 APK
3. 打开 App，选择时长，点击"开始"

## 🛠️ 自行编译

```bash
# 1. 克隆项目
git clone https://github.com/feier3388992/timeliss.git
cd timeliss

# 2. 安装依赖
npm install

# 3. 同步到 Android
npx cap sync

# 4. 用 Android Studio 打开 android/ 文件夹
# 5. Build -> Build APK
```
